# Follow Up Boss Connector — идеальный первый запуск

Источник: `ONBOARDING_FIRST_LAUNCH_STANDARD.md`. Целевой пользователь: риелтор/брокер
недвижимости, использующий Follow Up Boss CRM.

## 1. Credential type
API key (`fka_...` формат) + system_name (идентификатор интеграции для FUB).

## 2. Идеальный флоу
1. **Первое открытие** — `Empty` со ссылкой "Admin > API screen" + объяснение формата
   ключа (`fka_...`) для узнаваемости.
2. **Форма** — api_key (password-type, placeholder `fka_...`) + system_name (с
   объяснением — это как идентифицирует себя Imperal в логах FUB, не пользовательское
   имя).
3. **После успеха** — сводка новых лидов сегодня + "горячие" лиды ждущие звонка —
   сразу, максимально actionable для риелтора, который работает "с колёс".
4. **Real-time urgency framing** — идеально: real estate — очень time-sensitive
   ниша (лид "остывает" за часы) — первый экран должен визуально выделять СРОЧНОСТЬ
   (badge с цветом/временем с момента прихода лида), не просто список.
5. **Ошибка "invalid api key format"** — если введён не `fka_`-формат ключ — client-side
   подсказка сразу, до отправки на сервер.
